# qr-tool

**English** | [简体中文](README.zh.md)

本地 QR 码增强工具——单 HTML 页面、零服务器、纯浏览器运行。把低分辨率二维码 / 微信小程序码增强为高清 PNG / SVG，用于印刷物料。

## 能力

- **标准 QR（含带 logo）— 语义重建（矢量、无损）**：检测模块网格 → 逐模块采样 → 矢量重绘——任意分辨率锐利，保留原码模块排列、配色、间隙圆角、中心 logo
- **增强重绘 / 原图放大 切换**：对重绘结果不满意，一键切到像素保真放大
- **微信圆形码 — 像素保真放大**：彩色创意码原样保留 + 高质量插值放大（不做结构重建——会丢色彩/创意）
- **闭环自检**：每个重绘码都重新解码、与原内容逐字符比对——绝不输出未验证的码
- **预览 = 下载**：预览即下载结果（1184px PNG，或内嵌 logo 的矢量 SVG）
- **兜底链**：重绘失败 → 自动降级为像素保真放大（绝不报错）
- **长内容支持**：高版本码（77+ 模块）、URL 参数/埋点逐字符保留

## 使用方法

```bash
python3 -m http.server 8123
# 打开 http://localhost:8123/ui/index.html
```

拖拽图片到页面（或点选文件）。工具自动识别码类型、处理，可下载 PNG / SVG。

## 架构

```
输入 → 类型识别
  ├─ 微信圆形码 → 像素保真放大（彩色创意码，无法重建）
  └─ 标准 QR → 语义重建（检测网格 → 采样模块 → 矢量重绘）
       └─ 重建失败 → 像素保真放大（兜底）
```

- **语义重建**（`src/qr/`）：模块网格定位（finder 三角 + 对齐）、逐模块采样、矢量重绘（保留配色/间隙圆角/logo——白环检测 + 区域生长）
- **像素保真放大**（`src/wechat.js`）：Catmull-Rom 三次插值
- **清晰度检测**（`src/quality.js`）：边缘梯度锐度（预留）

## 技术栈

- 纯 JS（ESM）、零构建——浏览器经 import map 直接运行 `src/` 模块
- 测试：`node:test` 零依赖（`npm test`）
- 解码：jsQR + zxing（兜底）；QR 生成：qrcode-generator（测试用）
- 单 HTML UI（`ui/`），全程本地处理（不上传服务器）
